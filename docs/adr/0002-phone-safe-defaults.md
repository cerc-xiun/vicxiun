# Phone-safe defaults

The default Profile is phone-safe: it caps resolution and picks codecs and a
container that any ordinary phone can play, so that pasting a link is enough to
get a working file. The project exists to save people from having to know about
codecs and containers, and the moment that knowledge is forced on them is a
file that will not open on a phone — so safety is the default and quality is
something the user asks for by name.

**_Rejected_**: defaulting to the highest available quality. It would produce
the largest file the requester's device is least likely to play, and anyone who
genuinely wants the maximum has an explicit Profile for it.
